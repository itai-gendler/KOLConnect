# Creator/account selection

## Trigger

Choose activity, canonical profiles and eligible execution identities.

## Outcome

Campaign detail adds the selected profile with eligible chosen execution accounts.


## Edge cases

- Optional quote, cost, planned-date and actual-publication inputs must satisfy their declared validation before participation creation.
- An already-active duplicate participation found at this ordinary detail creation boundary is refused; library batch reuse/restoration has its own declared outcome.
- If the subsequent execution request fails, preceding participation and supplied publication creation remain persisted and the separate failure is reported.
